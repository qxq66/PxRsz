# Float Radio Switch

Eigenstaendiges ComfyUI-Paket. Den Ordner `PxFloatRadioSwitch` nach `ComfyUI/custom_nodes/` kopieren (oder verlinken) und ComfyUI neu starten.

- Pro Zeile: Eingang links, Zahlenfeld (>= 2 Nachkommastellen), Radio-Button rechts
- Dropdown `inputs` (2-20) unter dem Ausgang, Standard: 2 Zeilen
- Ein Ausgang `value` (FLOAT) mit dem aktiven Wert
